AFTER OPENING THAT LINK, YOU'LL SEE MULTIPLE TABS AT THE TOP:

[Overview] [Add-ons] [Deploys] [Events] [Settings] [Environment]

════════════════════════════════════════════════════════════════════════════════
STEP 1: CLICK "Add-ons" TAB
════════════════════════════════════════════════════════════════════════════════

This is where Redis and PostgreSQL services are configured.

You should see:
- PostgreSQL (if created)
- Redis (if created)
- Option to "Create PostgreSQL" or "Create Redis"

════════════════════════════════════════════════════════════════════════════════
STEP 2: GET REDIS DETAILS
════════════════════════════════════════════════════════════════════════════════

If Redis exists:
  1. Click on "Redis" in the Add-ons list
  2. You'll see connection details:
     - Host: redis-xxxxx.render.internal
     - Port: 6379
     - Password: xxxxxxxxxxxxxxxxxxxx

COPY AND PASTE THESE IN ENVIRONMENT TAB:
  REDIS_HOST = (the Host value)
  REDIS_PORT = 6379
  REDIS_PASSWORD = (the Password value)

If Redis DOESN'T exist:
  1. Click "Create New" → "Create Redis"
  2. Enter name: "outbox-email-scheduler-redis"
  3. Click "Create Redis"
  4. WAIT 2-5 MINUTES (it's provisioning)
  5. Once ready, copy details as shown above

════════════════════════════════════════════════════════════════════════════════
STEP 3: GET POSTGRESQL DETAILS
════════════════════════════════════════════════════════════════════════════════

If PostgreSQL exists:
  1. Click on "PostgreSQL" in the Add-ons list
  2. You'll see connection string:
     postgresql://postgres:password@hostname.render.internal:5432/email_scheduler

COPY AND PASTE IN ENVIRONMENT TAB:
  DATABASE_URL = (the full connection string)

If PostgreSQL DOESN'T exist:
  1. Click "Create New" → "Create PostgreSQL"
  2. Database name: "email_scheduler"
  3. Click "Create PostgreSQL"
  4. WAIT 2-5 MINUTES (it's provisioning)
  5. Once ready, copy connection string as shown above

════════════════════════════════════════════════════════════════════════════════
STEP 4: CLICK "Environment" TAB TO PASTE VALUES
════════════════════════════════════════════════════════════════════════════════

Now go back to the Environment tab (same top tabs):

[Overview] [Add-ons] [Deploys] [Events] [Settings] [Environment] ← CLICK HERE

You'll see the list of all environment variables.

Find or create these variables:

REDIS_HOST = redis-xxxxx.render.internal
REDIS_PORT = 6379
REDIS_PASSWORD = xxxxxxxxxxxxxxxxxxxx
DATABASE_URL = postgresql://postgres:password@hostname.render.internal:5432/email_scheduler

════════════════════════════════════════════════════════════════════════════════
STEP 5: CLICK "Save Changes"
════════════════════════════════════════════════════════════════════════════════

Scroll to the bottom of the Environment tab.

You'll see a button: "Save Changes"

Click it.

Render will automatically restart your service.
WAIT 2-3 MINUTES for the service to restart.
